Вариант 8: «Кулинар и фуд-блогер» — базовый JavaScript: расчёт калорийности блюд

Требования
- Ввод/вывод: `prompt`, `alert`, `console.log`
- Условные конструкции и циклы
- Функции: поиск максимума, фильтрация массива, подсчёт суммы
- Данные: массив из 5–7 чисел — калорийность блюд в ккал
- Логика варианта: фильтрация блюд > 600 ккал, подсчёт блюд ≤ 300 ккал и их доли, вывод общей калорийности и калорийности высококалорийных блюд
- Дополнительно: если сумма > 3000 ккал, вывести рекомендацию в консоль

Реализация
В файле `script.js` создан массив калорийности из 7 блюд. С помощью функции `findMax` находится максимальная калорийность, функция `filterHighCalorie` отбирает блюда с калорийностью больше 600 ккал, функция `calculateSum` считает сумму калорий. Цикл `for` подсчитывает количество низкокалорийных блюд (≤ 300 ккал), после чего считается их доля в процентах. Имя пользователя запрашивается через `prompt`, основной результат выводится через `alert`, а подробная информация — через `console.log`.
